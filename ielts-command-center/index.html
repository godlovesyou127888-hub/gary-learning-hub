Listening 聽力

先救：定位／口音／拼字
常見卡點：聽得到但來不及定位、不同口音聽不穩、答案拼字失分。
  • 先用 Mini Test 看錯誤分布
  • 如果是口音：進 Accent Lab
  • 如果是定位／拼字：重做錯題＋限時聽寫
先測 ListeningAccent Lab

Reading 閱讀

先救：速度／定位／同義替換
常見卡點：看得懂但做不完、關鍵字找錯、被同義替換騙走。
  • 先確認是不是「時間不足」而非單字不足
  • 練段落定位與題目關鍵字
  • 記錄最常錯題型，不平均刷題
先測 ReadingSpeed Lab

Writing 寫作

先救：Task Response／結構／句子
常見卡點：知道很多單字，但不會回答題目、段落沒有邏輯、句型不穩。
  • Task 1：先會四段式與 Overview
  • Task 2：先會立場＋雙 PEEL
  • 再補 Band 7 句型與 collocations
先測 Writing免費 Task 1 電子書免費 Task 2 電子書

Speaking 口說

先救：Fluency／內容／詞塊
常見卡點：有想法但說不出來、答案太短、背答案感太重。
  • Part 1：Answer → Why → Example → Result
  • Part 2：9 Story Bank 反覆遷移
  • Part 3：用 PRECC 建立觀點

學習不是看「做了多少」，而是比較前後數據。每完成一個 2–4 週週期，就回到同一種測驗條件做一次驗證。

Listening / Reading

Writing / Speaking

看最低科是否上升；若最低科換了，再換下一個主攻科。
