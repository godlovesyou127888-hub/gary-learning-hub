# Gary Learning Hub

Gary Learning Hub 是所有學習網站的中央母站。

## 原則

- 所有新網站先加入這個 Hub。
- 各子網站只保留「回 Gary Learning Hub」與「聯絡站長」。
- 不再在每個子網站重複維護完整網站群組。
- 更新採小批次、人工審核優先。

## 目前內容

- 樂齡英語
- TOEIC / 英語檢定
- 文法與單字
- 學科複習
- AI 工具
- 雙語品格教育

## 維護流程

Gary 提出新增或修改需求 → ChatGPT 修改 repository → 自動部署服務更新公開網站。

> Repository 暫時使用既有空白 repo `hi` 初始化。待 GitHub 端將名稱改為 `gary-learning-hub` 後，即作為正式母站。
