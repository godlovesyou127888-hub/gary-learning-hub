研究與作答說明｜Research Instructions

請根據你最近三個月學習或使用英文的實際經驗，判斷你對每個敘述的同意程度。所有題目均為同方向計分：分數越高，代表該類英文學習瓶頸越明顯。

Please answer based on your actual English learning or use during the past three months. All items are scored in the same direction: a higher score indicates a more pronounced learning bottleneck.

研究使用提醒｜Research note
目前版本是「研究工具原型」，尚未完成正式的內容效度、建構效度、信度或跨語言等值性驗證。未完成驗證前，不宜在論文中稱為「已驗證量表（validated scale）」。

Likert 五點量尺｜5-point Likert Scale

樂齡友善設計：本頁採較大字級、高對比、寬行距與大型選項。請直接點選整個選項方框，不需要精準點擊小圓圈。

診斷結果｜Diagnostic Results

構面分數以該構面四題平均值（1–5）呈現；100分指標 = 平均值 × 20。這是描述性學習診斷，不等同 CEFR、TOEIC、IELTS 或其他正式能力測驗。

五構面架構｜Five-Construct Framework

Input 輸入理解：聽力與閱讀的即時理解。
Output 輸出表達：口說與寫作的可用輸出。
Language System 語言系統：單字、搭配與文法系統。
Process 學習流程：診斷、方法、錯誤回饋與持續性。
Performance 情境表現：限時、考試與真實使用情境下的穩定度。
